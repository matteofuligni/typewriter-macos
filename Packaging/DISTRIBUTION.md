# Public distribution review

Reviewed November 16, 2026 for the default Apple Silicon build.

## Distribution channels

- **Direct download:** Apple supports distributing macOS apps on a website or through a release host. Use a Developer ID Application certificate with Hardened Runtime and a secure timestamp. Package the signed build as a ZIP or DMG, submit it to the notary service, staple the ticket, and test a downloaded copy on an Apple Silicon Mac without a pre-existing TeX installation. The current build script signs ad hoc for local testing. [Apple distribution overview](https://developer.apple.com/macos/distribution) · [Notarization requirements](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution) · [Packaging and stapling](https://developer.apple.com/documentation/xcode/packaging-mac-software-for-distribution)
- **Mac App Store:** The current TeX Live installer downloads native executables and runs installer scripts. Apple's rules on self-contained builds and downloaded code make that approach unsuitable for the Store. A candidate Store design would include a signed, sandboxed compiler and enough resources to compile a basic project offline. [Apple App Review Guidelines §§2.4.5 and 2.5.2](https://developer.apple.com/app-store/review/guidelines/#hardware-compatibility) · [Apple guidance on embedded tools](https://developer.apple.com/documentation/xcode/embedding-a-helper-tool-in-a-sandboxed-app)
- **Packages on demand:** The Mac App Store listing for Texifier describes a built-in typesetter and a manager that downloads and updates LaTeX packages. This is a precedent for testing a similar design, with App Review deciding whether to accept this app's implementation. Prototype a small, versioned catalog of upstream packages for the embedded compiler. Keep the scope to package files the compiler can load as part of typesetting, and exclude native executables and installer scripts. Explain the downloads in the App Review notes. Direct downloads from CTAN avoid redistributing those specific files ourselves. Files included in the app or hosted by the publisher require their own redistribution review. [Texifier listing](https://apps.apple.com/us/app/texifier-latex-editor/id458866234?mt=12) · [TeX Live copying conditions](https://github.com/TeX-Live/installer/blob/master/LICENSE.TL)
- **Product name:** Another writing application for Apple Silicon already uses the public name “Typewriter.” Clear or change the name before publishing. This is an observed name collision. Trademark registration and rights in specific territories need separate checks. [Existing Typewriter product](https://trytypewriter.com/)

## License inventory

| Material | Finding |
| --- | --- |
| Swift sources, templates, icon and sound effects | Typewriter's own code and assets use the [MIT License](../LICENSE). The icon and 30 sound clips are generated by scripts in this repository. SwiftPM declares no external packages. |
| macOS frameworks, system symbols and fonts | The app uses the installed frameworks, symbols and fonts. The default app bundle contains no font binaries. Document export is subject to the fonts' embedding permissions. The regular Times New Roman on the test Mac reports OpenType embedding flag `0x0008` (editable embedding). [Apple fonts guidance](https://developer.apple.com/documentation/technologyoverviews/fonts) · [macOS license](https://www.apple.com/legal/sla/docs/macOSSequoia.pdf) · [OpenType `fsType`](https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fstype) |
| TeX Live in the default build | The app invokes pdfLaTeX as a separate process. The default bundle contains neither TeX Live binaries nor its packages. The user can download the upstream installer and packages from a CTAN mirror. This avoids redistributing those TeX files in the app download. [TeX Live copying conditions](https://github.com/TeX-Live/installer/blob/master/LICENSE.TL) |
| Optional bundled TeX build | Treat this variant as a development build until the exact bundled files are audited. `LICENSE.TL` and `LICENSE.CTAN` alone do not cover the conditions of each bundled component. Inventory the binaries, macros, formats and fonts, retain their notices, document changes to the distribution, and provide corresponding source wherever the applicable license requires it. pdfTeX is GPL-licensed. [TeX Live copying conditions](https://github.com/TeX-Live/installer/blob/master/LICENSE.TL) · [pdfTeX license listing](https://ctan.org/pkg/pdftex) |

The app compiles documents locally. Its TeX Live installation and package lookup requests go to CTAN. Before distributing the default binary publicly, check the product name, sign with Developer ID, notarize it, and test it with Gatekeeper.
